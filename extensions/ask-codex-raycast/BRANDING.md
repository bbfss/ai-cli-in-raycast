# AI CLI in Raycast assets

The extension and its command suite use `assets/suite-icon.png`. Its editable
source is `assets/suite-icon.svg`; `assets/cli-avatar.svg` uses the same design
inside conversations. The original `command-icon.png` remains as an unused
legacy asset.

The new terminal-chevron, cyan cursor, and signal-node SVG was authored by
Gemini through native Antigravity CLI model `gemini-3.8-flash-high` on
2026-10-21. The 512 × 512 PNG was mechanically rendered with Resvg and visually
checked at smaller sizes. Resvg is an authoring tool, not an extension dependency.

The attempted Magpie Gemini route returned HTTP 402. The successful SVG work
used native Antigravity; it was not a Magpie image-generation request. Two
separate Gemini web image attempts had a baked checkerboard background and
were not adopted. No provider or Raycast logo was traced into the new icon.

This is development branding. Store publication remains withdrawn; review
branding, screenshots, and current Store requirements before any future
user-authorized application.
